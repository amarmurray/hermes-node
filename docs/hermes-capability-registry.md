# Hermes Capability Registry

This is the membrane view of upstream Hermes capabilities.

## Wrapped Now

- upstream CLI/runtime substrate
- provider/model selection through Hermes-node task metadata and operator policy
- read-first repo execution through routing, approvals, ledger, and workspaces
- durable session, workspace, and receipt artifacts

## Candidates Later

- local-only operator/API seam for Temporal or Mini App use
- bounded monitor loops
- additional executor lanes such as Claude or specialist paths

## Withheld For Now

- public gateway exposure
- any attempt to treat Hermes-node as a Temporal replacement
- unbounded repo mutation
- autonomous activation of upstream breadth before policy wraps it

Rule: broader upstream Hermes capability only becomes autonomous behavior after
Hermes-node policy wraps it.
